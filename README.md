# Online Food Ordering Database

## Project Description
The Online Food Ordering Database is a MySQL-based database project designed to manage customers, restaurants, food items, orders, order details, and payments efficiently.

## Entities
- Customers
- Restaurants
- FoodItems
- Orders
- OrderDetails
- Payments

## Features
- Database and table creation
- Primary and foreign keys
- Insert, Update and Delete operations
- CRUD operations
- Views
- Stored Procedures
- Subqueries
- Aggregate Functions
- GROUP BY operations

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Project File
`online_food_ordering_database.sql`
